# Predicting Serious Injuries in Barcelona Accidents

Analyse Barcelona traffic accidents and predict the serious injuries suffered in each one.

## Approach

- Exploratory analysis by district, street and time
- Logistic Regression and Random Forest models

## Results

Accuracy of about 0.98 in the saved notebook output. Read this alongside the class balance of the target.
